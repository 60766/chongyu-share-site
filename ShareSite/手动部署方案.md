# Vercel 手动部署方案

## 🔍 问题分析

Vercel 自动部署持续失败，可能的原因：
1. 项目根目录配置不正确
2. 构建配置问题
3. 文件路径问题

## 🚀 解决方案

### 方案1：通过 Vercel 网页控制台手动上传（最简单）

1. **登录 Vercel**
   - 访问：https://vercel.com
   - 登录你的账户

2. **进入项目**
   - 找到 `share.chongyuai.com` 或 `chongyu-share-site` 项目
   - 点击进入项目详情

3. **手动上传文件**
   - 点击 "Settings"（设置）
   - 找到 "Deployments" 或 "Deploy" 选项
   - 选择 "Upload" 或 "Deploy from local files"
   - 上传以下文件：
     - `index.html`
     - `privacy.html`
     - `terms.html`
     - `vercel.json`
     - `.well-known/apple-app-site-association`（如果有）

4. **触发部署**
   - 点击 "Deploy" 按钮

### 方案2：检查并修复 Vercel 项目设置

1. **检查根目录配置**
   - 进入项目 Settings
   - 查看 "Root Directory" 设置
   - 确保设置为 `/`（根目录）或留空

2. **检查构建配置**
   - 查看 "Build & Development Settings"
   - 确保：
     - Framework Preset: Other
     - Build Command: 留空（静态网站不需要构建）
     - Output Directory: 留空或设置为 `/`
     - Install Command: 留空

3. **重新部署**
   - 在 Deployments 页面
   - 找到最新的部署
   - 点击 "Redeploy"

### 方案3：使用 Vercel CLI（如果已安装）

```bash
# 安装 Vercel CLI（如果未安装）
npm i -g vercel

# 登录
vercel login

# 在项目目录部署
cd "/Users/lishilong/IOS开发/虫遇/虫遇/ShareSite"
vercel --prod
```

### 方案4：检查并修复 Git 仓库结构

如果 Vercel 连接的是 GitHub，确保文件在正确的位置：

```bash
cd "/Users/lishilong/IOS开发/虫遇/虫遇/ShareSite"

# 确认根目录文件是最新的
ls -la index.html privacy.html terms.html vercel.json

# 确认文件内容正确
grep -n "冀ICP备\|冀公网安备\|li2410669277@gmail.com" index.html

# 如果文件正确，强制推送
git add -A
git commit -m "强制更新所有文件"
git push origin main --force
```

⚠️ **注意**：`--force` 会覆盖远程仓库，请谨慎使用。

### 方案5：创建新的 Vercel 项目

如果以上方法都不行，可以创建新项目：

1. **在 Vercel 创建新项目**
   - 登录 Vercel
   - 点击 "Add New Project"
   - 选择 "Import Git Repository"
   - 选择你的 GitHub 仓库

2. **配置项目**
   - Framework Preset: Other
   - Root Directory: `/`（或留空）
   - 其他设置保持默认

3. **部署**
   - 点击 "Deploy"
