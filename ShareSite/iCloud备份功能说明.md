## 📋 功能详情

### 备份位置
```
iCloud Drive → Documents → 虫遇备份 → 虫遇备份_YYYYMMDD_HHmmss.json
```

### 自动备份规则
- 默认关闭，用户可手动开启
- 开启后每7天自动备份一次
- 在用户导出数据时，如果满足条件会自动备份
- 最多保留最近5个备份文件

### 备份内容
- 用户资料（昵称、签名、等级等）
- 我的创作（帖子、自定义角色）
- 成长记录（统计数据）

## 🔧 配置要求

### Xcode项目配置

1. **启用iCloud能力**
   - 在Xcode中打开项目
   - 选择Target → Signing & Capabilities
   - 点击 "+ Capability"
   - 添加 "iCloud"
   - 勾选 "iCloud Documents"

2. **Info.plist配置**（如果需要）
   - 通常不需要额外配置
   - iOS会自动处理iCloud Drive权限

### 用户端要求

1. **登录iCloud**
   - 用户需要在设备上登录iCloud账号
   - 开启iCloud Drive功能

2. **权限**
   - 首次使用时会自动请求iCloud Drive权限
   - 用户需要在设置中允许应用访问iCloud Drive

## 🎯 使用流程

### 手动备份
1. 进入"账号管理" → "数据管理"
2. 点击"导出数据"
3. 在导出页面点击"保存到iCloud Drive"
4. 等待保存完成

### 自动备份
1. 进入"账号管理" → "数据管理"
2. 开启"iCloud自动备份"开关
3. 系统会在满足条件时自动备份（每7天一次）

### 查看备份历史
1. 进入"账号管理" → "数据管理"
2. 点击"备份历史"
3. 查看所有备份文件
4. 可以删除不需要的备份

## ⚠️ 注意事项

1. **iCloud空间**
   - 备份文件会占用iCloud存储空间
   - 建议用户确保有足够的iCloud空间

2. **网络要求**
   - 保存到iCloud需要网络连接
   - 首次上传可能需要一些时间

3. **隐私保护**
   - 备份文件存储在用户的iCloud Drive中
   - 只有用户本人可以访问
   - 应用不会访问其他iCloud文件

4. **备份限制**
   - 最多保留5个备份文件
   - 超出限制会自动删除最旧的备份

## 🐛 故障排除

### iCloud不可用
- 检查是否登录iCloud
- 检查是否开启iCloud Drive
- 检查网络连接

### 保存失败
- 检查iCloud存储空间
- 检查网络连接
- 尝试重新保存

### 备份历史为空
- 确认已保存过备份
- 检查iCloud Drive权限
- 尝试下拉刷新
