# 🔧 私聊输入框高度异常修复总结

## 📅 修复时间
2025年9月27日

## 🎯 问题描述
私聊界面的输入框高度异常，显示过高，影响用户体验。

## 🔍 问题分析

### 根本原因
1. **重复的背景设置**：`ChatInputBar.swift` 中存在多处背景配置，导致视觉冲突
2. **初始高度不合理**：初始高度设置为36，过小导致计算异常
3. **自动获得焦点**：组件出现时立即获得焦点，可能引起高度跳变
4. **高度计算缺乏安全检查**：`MultiChatTextView` 的高度计算没有足够的边界检查

### 涉及的文件
- `虫遇/Views/Components/ChatInputBar.swift` - 私聊输入框组件
- `虫遇/Views/MultiPersonChat/MultiChatTextView.swift` - 文本视图组件

## ✅ 修复措施

### 1. 优化 ChatInputBar.swift
- **调整初始高度**：从36改为40，提供更合理的起始高度
- **移除重复背景**：删除多余的背景配置，统一使用单一背景设置
- **移除自动焦点**：删除 `onAppear` 中的自动获得焦点逻辑
- **优化高度变化检测**：增加变化阈值（从无限制改为>2点才更新）
- **缩短动画时间**：从0.3秒缩短为0.2秒，提升响应速度
- **调整内边距**：优化占位符和文本区域的内边距

### 2. 增强 MultiChatTextView.swift 的安全性
- **添加frame检查**：确保textView有有效的frame再进行计算
- **设置高度范围**：最小40，最大120，防止异常高度
- **空文本处理**：文本为空时强制使用最小高度
- **缩短动画时间**：从0.25秒缩短为0.2秒

### 3. 具体代码改动

#### ChatInputBar.swift 主要修改：
```swift
// 调整初始高度
@State private var textViewHeight: CGFloat = 40  // 从36改为40

// 优化高度计算回调
MultiChatTextView(text: $messageText, isFocused: $textFieldFocused, heightChanged: { height in
    let clampedHeight = max(40, min(height, 100))  // 限制范围
    if abs(clampedHeight - textViewHeight) > 2 {  // 增加变化阈值
        withAnimation(.easeInOut(duration: 0.2)) {  // 缩短动画时间
            textViewHeight = clampedHeight
        }
    }
})

// 移除自动获得焦点的代码
// .onAppear { ... } 代码块已删除
```

#### MultiChatTextView.swift 主要修改：
```swift
func calculateAndUpdateHeight(_ textView: UITextView) {
    guard let heightChanged = heightChanged else { return }
    
    // 确保textView有有效的frame
    guard textView.frame.width > 0 else { return }
    
    // 添加安全范围限制
    let minHeight: CGFloat = 40
    let maxHeight: CGFloat = 120
    newHeight = max(minHeight, min(newHeight, maxHeight))
    
    // 如果文本为空，使用最小高度
    if textView.text.isEmpty {
        newHeight = minHeight
    }
}
```
