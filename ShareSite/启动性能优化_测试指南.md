## 故障排查

### 问题1：图片不显示
**症状**：某些角色头像显示为空白或占位图

**排查步骤**：
1. 检查日志中是否有错误信息
2. 确认该图片是否在 `knownMissingImages` 列表中
3. 重置首次检查标志，重新复制图片
4. 检查 Documents/HistoricalFigures 目录下是否有该图片文件

**解决方法**：
```swift
// 如果图片文件确实存在但被标记为缺失，从列表中移除：
private let knownMissingImages = [
    // 移除该角色ID
]
```

### 问题2：启动仍然很慢
**症状**：即使后续启动也很慢

**排查步骤**：
1. 检查日志，确认是否输出了 "⚡️ 图片快速检查完成"
2. 如果没有，说明首次检查标志可能未设置成功
3. 检查其他可能的性能瓶颈（如网络请求、数据库查询等）

**解决方法**：
- 确保首次启动完成后重启应用
- 检查 UserDefaults 是否正常工作
- 查看其他日志，找出新的性能瓶颈

### 问题3：首次启动失败
**症状**：首次启动时图片复制失败

**排查步骤**：
1. 检查日志中的错误信息
2. 确认 Documents 目录是否可写
3. 检查图片资源是否正确打包到应用中

**解决方法**：
- 重新构建应用
- 检查 Assets.xcassets 中的图片资源
- 确认文件权限正常

## 监控启动性能

### 添加性能监控
可以在 `__App.swift` 的 `init()` 中添加：

```swift
init() {
    let appStartTime = CFAbsoluteTimeGetCurrent()
    
    // ... 现有初始化代码 ...
    
    let initTime = CFAbsoluteTimeGetCurrent() - appStartTime
    #if DEBUG
    print("📊 应用初始化耗时: \(String(format: "%.2f", initTime * 1000))ms")
    #endif
}
```

### 分析性能瓶颈
查看日志中各个步骤的耗时：
- API配置初始化
- 数据迁移
- 点赞服务初始化
- 图片复制检查
- StoreKit 产品加载

找出最慢的步骤，针对性优化。

✅ **必须满足**：
