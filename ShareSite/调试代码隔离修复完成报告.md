## 🔧 修复模板

### 标准修复

```swift
// ❌ 修复前
print("调试信息: \(value)")

// ✅ 修复后
#if DEBUG
print("调试信息: \(value)")
#endif
```

### 使用Logger（推荐）

```swift
// ❌ 修复前
print("网络请求: \(url)")

// ✅ 修复后（推荐）
#if DEBUG
Logger.network.debug("网络请求: \(url)")
#endif
```

### 错误日志

```swift
// ❌ 修复前
print("❌ 错误: \(error)")

// ✅ 修复后（推荐）
Logger.error("错误", error: error)
```

## ⚠️ 重要提醒

1. **不要修复用户消息**
   - 如果print用于显示给用户，应该改为Toast/Alert
   - 不要用#if DEBUG包裹

2. **关键错误处理**
   - 使用Logger.error（会自动处理生产环境）
   - 或保留在生产环境

3. **测试每个修复**
   - DEBUG模式：确认日志正常
   - RELEASE模式：确认不输出调试信息
