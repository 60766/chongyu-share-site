### 方式2: 手动重启

```bash
# 1. 进入backend目录
cd /Users/lishilong/IOS开发/虫遇/虫遇/backend

# 2. 停止旧进程
OLD_PID=$(ps aux | grep "node.*server.js" | grep -v grep | awk '{print $2}')
if [ -n "$OLD_PID" ]; then
  kill $OLD_PID
  echo "已停止进程: $OLD_PID"
fi

# 3. 等待进程完全停止
sleep 2

# 4. 启动新服务器
nohup node server.js > server.log 2>&1 &
echo "新服务器已启动: PID=$!"

# 5. 查看日志验证
sleep 3
tail -20 server.log
```
