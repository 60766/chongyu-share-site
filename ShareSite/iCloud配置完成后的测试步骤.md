# iCloud 配置完成后的测试步骤

## ✅ 配置状态确认

从截图看到：
- ✅ "iCloud Documents" 已勾选
- ✅ iCloud 能力已添加
- ✅ 配置看起来正确

## 🧪 接下来需要做的

### 1. 重新构建项目
1. 在 Xcode 中，按 `Cmd + Shift + K` 清理构建
2. 按 `Cmd + B` 重新构建项目
3. 确保没有编译错误

### 2. 在真机上测试（重要！）
⚠️ **注意**：iCloud Drive 功能在模拟器上可能无法完全测试，建议在真机上测试。

**真机测试步骤：**
1. 连接 iPhone/iPad 到 Mac
2. 在 Xcode 中选择真机作为运行目标
3. 确保设备已登录 iCloud 账号
4. 确保设备已开启 iCloud Drive：
   - 设置 → [你的名字] → iCloud → iCloud Drive → 开启

### 3. 运行应用并测试备份功能

#### 步骤1：检查 iCloud 可用性
1. 运行应用
2. 进入：**设置** → **账号管理** → **数据管理**
3. 查看是否显示 **"iCloud自动备份"** 开关
   - ✅ 如果看到开关：说明 iCloud 可用，继续下一步
   - ❌ 如果看不到：检查设备是否登录 iCloud

#### 步骤2：测试手动备份
1. 在"数据管理"页面，点击 **"导出数据"**
2. 等待数据导出完成
3. 在导出页面，点击 **"保存到iCloud Drive"** 按钮
4. 观察：
   - 按钮显示"正在保存..."
   - 等待几秒钟
   - 显示"保存成功"提示

#### 步骤3：验证备份文件
1. 打开 iOS **"文件"** 应用
2. 点击左侧 **"iCloud Drive"**
3. 查找并进入 **"虫遇备份"** 文件夹
4. 应该能看到备份文件，文件名类似：`虫遇备份_20241215_143022.json`

#### 步骤4：测试自动备份
1. 在"数据管理"页面，开启 **"iCloud自动备份"** 开关
2. 再次点击"导出数据"
3. 如果距离上次备份超过7天，会自动触发备份
4. 检查备份历史是否更新

#### 步骤5：查看备份历史
1. 在"数据管理"页面，点击 **"备份历史"**
2. 应该能看到所有备份文件列表
3. 可以查看备份时间、大小等信息
4. 可以删除不需要的备份

## 🔍 验证清单

完成测试后，确认以下项目：

- [ ] iCloud 可用性检查通过（能看到"iCloud自动备份"开关）
- [ ] 手动备份成功（能保存到iCloud Drive）
- [ ] 能在"文件"应用中看到备份文件
- [ ] 备份历史功能正常

## ⚠️ 可能遇到的问题

### 问题1：看不到"iCloud自动备份"开关
**原因：**
- 设备未登录 iCloud
- 未开启 iCloud Drive
- 网络连接问题

**解决：**
1. 检查：设置 → [你的名字] → 确认已登录 iCloud
2. 检查：设置 → [你的名字] → iCloud → iCloud Drive → 确认已开启
3. 检查网络连接
4. 重启应用

### 问题2：保存到iCloud失败
**原因：**
- iCloud 存储空间不足
- 网络连接问题
- 权限问题

**解决：**
1. 检查 iCloud 存储空间：设置 → [你的名字] → iCloud → 管理存储空间
2. 检查网络连接
3. 重新尝试保存

### 问题3：备份历史为空
**原因：**
- 还没有保存过备份
- iCloud Drive 权限问题

**解决：**
1. 先手动保存一次备份
2. 下拉刷新备份历史
3. 检查"文件"应用中的备份文件夹

### 问题4：在模拟器上测试
**说明：**
- 模拟器可能无法完全测试 iCloud Drive
- 建议在真机上测试

**如果必须在模拟器测试：**
1. 确保模拟器已登录 iCloud（设置 → 登录）
2. 但某些功能可能仍然无法正常工作
