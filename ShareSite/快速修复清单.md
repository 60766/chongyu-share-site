#### 修改步骤

**步骤1: 修改Xcode配置**
```
1. 打开 Xcode
2. 选择项目 "虫遇"
3. 选择 Target "虫遇"
4. General → Deployment Info
5. "Minimum Deployments" 改为 iOS 16.0
6. Cmd+S 保存
```

**步骤2: 检查代码兼容性**

需要检查的iOS 17+独有API：

```bash
# 搜索可能的iOS 17+ API
cd "虫遇/虫遇"

# @Observable (iOS 17+)
grep -r "@Observable" --include="*.swift" .

# ContentUnavailableView (iOS 17+)
grep -r "ContentUnavailableView" --include="*.swift" .

# #Preview (iOS 17+)
grep -r "#Preview" --include="*.swift" .
```

**常见替换方案**:

```swift
// iOS 17+ → iOS 16兼容
@Observable → @ObservableObject + @Published
#Preview → struct XXX_Previews: PreviewProvider
ContentUnavailableView → 自定义空状态视图

// 条件编译
if #available(iOS 17.0, *) {
    // iOS 17+代码
} else {
    // iOS 16兼容代码
}
```

## 📞 遇到问题时的检查点

### 如果Build失败
1. 检查iOS版本相关的API兼容性
2. 查看错误信息，搜索iOS 17+独有API
3. 添加条件编译或替换为兼容API

### 如果图标不显示
1. 确认图片格式PNG（无透明）
2. 确认尺寸1024x1024
3. 确认Contents.json配置正确
4. Clean Build后重新运行

### 如果内购商品为空
1. 确认StoreKit.storekit配置正确
2. 确认Xcode Scheme配置了StoreKit文件
3. 重启Xcode
4. 查看控制台日志检查加载情况
