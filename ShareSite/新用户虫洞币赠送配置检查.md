# 新用户虫洞币赠送配置检查

## 检查时间
2025年1月

## 当前配置

### 1. 赠送金额
- **配置值：** `INITIAL_WELCOME_CREDITS=600`
- **配置文件：** `backend/production.env`
- **代码默认值：** 600虫洞币（如果环境变量未设置）
- **代码位置：** `backend/server.js` 第178行

```javascript
const INITIAL_WELCOME_CREDITS = Number(process.env.INITIAL_WELCOME_CREDITS || 600)
```

### 2. 赠送条件

#### ✅ 满足条件才会赠送：
1. **设备ID有效**
   - `deviceId` 不能为空
   - `deviceId` 长度至少16字符（`MIN_DEVICE_ID_LENGTH`）
   - `deviceId` 会被规范化（转小写、去空格）

2. **设备首次使用**
   - 该设备ID之前没有领取过赠送
   - 通过 `deviceWelcomeRecords` Map 记录设备领取历史
   - 每个设备只能领取一次

3. **调用余额接口时自动判断**
   - 当调用 `/balance` 接口时，如果钱包不存在，会自动创建
   - 创建时会检查是否符合赠送条件
   - 如果符合，自动赠送600虫洞币

#### ❌ 不满足条件的情况：
1. **设备ID无效**
   - `deviceId` 为空或长度不足16字符
   - 原因：`missing_or_invalid_device`

2. **设备已领取过**
   - 该设备ID之前已经领取过赠送
   - 原因：`device_already_granted`

3. **手动创建钱包时**
   - 如果调用 `getWallet(token, { allowWelcome: false })`，不会赠送
   - 用于管理员操作等场景

### 3. 赠送流程

```
用户首次打开应用
  ↓
调用 /balance 接口（带 deviceId）
  ↓
后端检查钱包是否存在
  ↓
如果不存在，调用 getWallet(token, { deviceId, allowWelcome: true })
  ↓
检查设备是否首次使用（evaluateWelcomeEligibility）
  ↓
如果符合条件：
  - 创建钱包
  - 设置余额为 600
  - 记录交易（type: 'gift', ref: 'new_user_welcome'）
  - 记录设备领取历史
  - 返回余额
```

### 4. 设备记录机制

**存储位置：** `deviceWelcomeRecords` Map
- Key: 规范化后的 `deviceId`
- Value: 
  ```javascript
  {
    firstToken: string,        // 首次使用的token
    giftCount: number,         // 领取次数（通常为1）
    firstGrantedAt: number,    // 首次领取时间戳
    lastToken: string,         // 最后使用的token
    lastAttemptAt: number      // 最后尝试时间戳
  }
  ```

**持久化：** 记录会保存到 `server-data.json` 文件中

### 5. 交易记录

每次赠送都会创建交易记录：
```javascript
{
  id: string,                    // 唯一ID
  type: 'gift',                  // 类型：赠送
  token: string,                 // 用户token
  amount: 600,                   // 金额
  ref: 'new_user_welcome',       // 引用：新用户欢迎
  meta: {
    reason: '新用户注册赠送',
    deviceId: string             // 设备ID
  },
  at: number                     // 时间戳
}
```

## 注意事项

1. **设备ID要求**
   - 确保iOS端正确传递 `X-Device-Id` 请求头
   - `deviceId` 长度必须至少16字符
   - 当前iOS端使用 `AppAccountManager.deviceIdentifier`（UUID格式，36字符）

2. **防止重复领取**
   - 基于设备ID判断，不是基于token
   - 同一设备即使创建新账号，也不会重复领取
   - 这是为了防止用户通过删除应用重新安装来重复领取

3. **数据持久化**
   - 设备记录保存在 `server-data.json` 中
   - 如果删除该文件，所有设备记录会丢失（可能导致重复领取）
   - 建议定期备份 `server-data.json` 文件

4. **日志记录**
   - 每次赠送都会记录日志：
     - 成功：`[Wallet] 新用户 xxx... 获得 600 虫洞币`
     - 失败：`[Wallet] 新用户 xxx... 创建钱包但未赠送虫洞币，原因=xxx`
