# Vercel 部署问题诊断

## 🔍 发现的问题

### 问题1：Git 仓库中有两套文件

Git 仓库中存在两套 HTML 文件：

1. **根目录文件**：
   - `index.html`
   - `privacy.html`
   - `terms.html`
   - `vercel.json`

2. **ShareSite/ 子目录文件**：
   - `ShareSite/index.html`
   - `ShareSite/privacy.html`
   - `ShareSite/terms.html`
   - `ShareSite/vercel.json`

### 问题2：Vercel 可能读取错误的目录

Vercel 默认从 Git 仓库的**根目录**读取文件。如果 Vercel 配置的根目录是根目录，但我们修改的是 `ShareSite/` 子目录中的文件，那么部署就会失败或显示旧内容。

---

## 🔧 解决方案

### 方案1：确认 Vercel 根目录配置（推荐）

1. **登录 Vercel 控制台**
   - 访问：https://vercel.com
   - 找到 `share.chongyuai.com` 项目

2. **检查项目设置**
   - 进入项目设置（Settings）
   - 查看 "Root Directory" 配置
   - 确认是根目录（`/`）还是 `ShareSite/` 子目录

3. **根据配置更新文件**
   - 如果根目录是 `/`：更新根目录的文件
   - 如果根目录是 `ShareSite/`：更新子目录的文件

### 方案2：统一文件位置（最简单）

将 `ShareSite/` 子目录中的最新文件复制到根目录：

```bash
cd "/Users/lishilong/IOS开发/虫遇/虫遇/ShareSite"
cp ShareSite/index.html index.html
cp ShareSite/privacy.html privacy.html
cp ShareSite/terms.html terms.html
cp ShareSite/vercel.json vercel.json
git add index.html privacy.html terms.html vercel.json
git commit -m "同步文件到根目录以修复部署"
git push origin main
```

### 方案3：修改 Vercel 根目录配置

如果 Vercel 配置的根目录是 `/`，但你想使用 `ShareSite/` 子目录：

1. 登录 Vercel 控制台
2. 进入项目设置
3. 修改 "Root Directory" 为 `ShareSite`
4. 重新部署
