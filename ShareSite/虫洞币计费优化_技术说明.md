# 🚀 虫洞币计费优化 - 技术说明

## 📊 优化前后对比

### 优化前（旧计费）
- **文本API**: 100虫洞币/1K tokens
- **视觉API**: 200虫洞币/1K tokens（2倍费率）
- **6元（648虫洞币）**: 约生成 3-4 篇帖子

### 优化后（新计费）
- **文本API**: 13虫洞币/1K tokens ✅
- **视觉API**: 13虫洞币/1K tokens ✅（移除不合理的2倍费率）
- **6元（648虫洞币）**: 约生成 **69 篇帖子** 🎉

**优化幅度**: **17倍提升！**

---

## 💰 定价策略依据

### API成本（火山引擎实际价格）
- **Deepseek R1**: 输入4元/M tokens，输出16元/M tokens
- **豆包视觉**: 输入0.8-2.4元/M tokens，输出8-24元/M tokens

### 单篇帖子成本计算
以DeepSeek R1生成1篇帖子为例：
- 输入：500 tokens × 4元/M = 0.002元
- 输出：1500 tokens × 16元/M = 0.024元
- **合计**: ~0.026元/篇

### 利润率策略
- **70%利润率**: 0.026元 ÷ 0.3 = 0.087元/篇（用户支付）
- 2000 tokens × 13虫洞币/1K = 26虫洞币
- 648虫洞币 ÷ 26 = **约69篇**

## 🔧 技术实现

### 1. 修改配置文件
**文件**: `backend/production.env`

```env
# 积分配置（优化后：70%利润率，6元可生成约69篇帖子）
# 计算依据：
# - API成本：输入4元/M tokens，输出16元/M tokens
# - 平均每篇：输入500tokens(0.002元) + 输出1500tokens(0.024元) ≈ 0.026元
# - 70%利润率：每千tokens消耗约13虫洞币
CREDITS_PER_1K_TOKENS=13
```

### 2. 移除视觉API的不合理2倍费率
**文件**: `backend/server.js`

**修改前**:
```javascript
// 视觉API成本更高，使用2倍费率
const costCredits = Math.ceil((totalTokens / 1000) * CREDITS_PER_1K_TOKENS * 2)
```

**修改后**:
```javascript
// 视觉API计费（豆包视觉价格：0.8-2.4元/M输入，8-24元/M输出，与文本API相当）
// 优化后统一费率，不再使用2倍乘数
const costCredits = Math.ceil((totalTokens / 1000) * CREDITS_PER_1K_TOKENS)
```

**优化原因**: 
- 豆包视觉API实际价格 **低于** 文本API
- 之前的2倍费率过度收费，不利于用户体验

## 🔒 注意事项

### 1. 不要修改内购档位
Apple审核通过的内购档位**不能随意修改**，否则需要重新审核。

### 2. 数据持久化
服务器使用 `server-data.json` 持久化：
- 所有用户余额
- 交易记录
- 已处理的IAP交易

重启服务器不会丢失数据。

### 3. 监控API成本
定期检查火山引擎账单：
```
API成本 / 收入 ≈ 30%（目标）
```
如果比例异常，及时调整 `CREDITS_PER_1K_TOKENS`。
