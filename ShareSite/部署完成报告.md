## 📊 配置详情

### Caddy配置
```
share.chongyuai.com {
    log {
        output file /var/log/caddy/share-access.log
        roll_size 10mb
        roll_keep 5
        format json
    }
    root * /var/www/share-site
    encode zstd gzip
    file_server
    try_files {path} /index.html
    header Cache-Control "no-cache, no-store, must-revalidate"
    header Pragma "no-cache"
    header Expires "0"
}
```
