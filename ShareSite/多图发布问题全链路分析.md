## 🛠️ 解决方案

### 方案A: 分批处理（最可靠）

如果豆包API确实有图片数量限制（如5张/次），可以分批调用：

```swift
// DoubaoVisionService.swift 新增方法
func analyzeImagesInBatches(
    _ images: [UIImage],
    batchSize: Int = 5,  // 每批最多5张
    postContent: String,
    characters: [String]
) -> AnyPublisher<[String: String], AINetworkError> {
    // 将图片分批
    let batches = stride(from: 0, to: images.count, by: batchSize).map {
        Array(images[$0..<min($0 + batchSize, images.count)])
    }
    
    print("📦 将\(images.count)张图片分为\(batches.count)批处理")
    
    // 依次处理每批
    return Publishers.Sequence(sequence: batches)
        .flatMap { batch -> AnyPublisher<[String: String], AINetworkError> in
            return self.analyzeImagesAndGenerateComments(
                batch,
                postContent: postContent,
                characters: characters
            )
        }
        .reduce(into: [String: String]()) { result, batch in
            result.merge(batch) { _, new in new }
        }
        .eraseToAnyPublisher()
}
```

### 方案C: 请求超时重试机制

```swift
// 添加重试逻辑
func analyzeWithRetry(_ images: [UIImage], ..., maxRetries: Int = 2) -> AnyPublisher<[String: String], AINetworkError> {
    return analyzeImagesAndGenerateComments(images, ...)
        .catch { error -> AnyPublisher<[String: String], AINetworkError> in
            if maxRetries > 0 {
                print("⚠️ 请求失败，\(maxRetries)次重试机会剩余，3秒后重试...")
                return Just(())
                    .delay(for: .seconds(3), scheduler: DispatchQueue.main)
                    .flatMap { _ in
                        return self.analyzeWithRetry(images, ..., maxRetries: maxRetries - 1)
                    }
                    .eraseToAnyPublisher()
            } else {
                return Fail(error: error).eraseToAnyPublisher()
            }
        }
        .eraseToAnyPublisher()
}
```
