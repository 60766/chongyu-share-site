# 403错误提示修复说明

## 问题描述

用户有虫洞币，但后端API额度不足时，返回403错误，但用户没有收到任何提示，不知道为什么内容没有生成。

## 修复内容

### 1. 在 `AINetworkError` 中添加403错误的友好提示

**文件：** `虫遇/Services/AINetworkService.swift`

**修改：**
- 在 `localizedDescription` 中添加了403错误的友好提示
- 提示内容：`"API服务暂时不可用，请联系客服或稍后重试"`

```swift
case .httpError(let code):
    if code == 402 {
        return "余额不足，请先充值"
    } else if code == 403 {
        return "API服务暂时不可用，请联系客服或稍后重试"
    }
    return "HTTP错误: \(code)"
```

### 2. 在 `AINetworkService` 中处理403错误时显示Toast

**文件：** `虫遇/Services/AINetworkService.swift`

**修改：**
- 在 `sendRequestWithPartialDataCapture` 方法中，当收到403错误时，显示Toast提示
- 同时标记后端为忙碌状态

```swift
if httpResponse.statusCode != 200 {
    print("❌ Non-200 status: \(httpResponse.statusCode)")
    
    // 403错误：API额度不足或服务不可用
    if httpResponse.statusCode == 403 {
        Task { @MainActor in
            ContentGeneratorService.shared.markBackendBusy(true)
            // 显示友好的错误提示
            ToastManager.shared.showToast(message: "API服务暂时不可用，请联系客服或稍后重试")
        }
    } else {
        Task { @MainActor in
            ContentGeneratorService.shared.markBackendBusy(true)
        }
    }
    
    promise(.failure(.httpError(httpResponse.statusCode)))
    return
}
```

### 3. 在 `ContentGeneratorService` 中添加错误提示

**文件：** `虫遇/Services/ContentGeneratorService.swift`

**修改：**
- 在AI生成内容和评论失败时，显示友好的错误提示
- 避免403错误重复显示Toast（因为已经在 `AINetworkService` 中显示）

```swift
if case .failure(let error) = completion {
    print("❌ AI生成内容和评论失败: \(error.localizedDescription)")
    
    // 显示友好的错误提示给用户
    // 注意：403错误已经在AINetworkService中显示Toast，这里避免重复显示
    Task { @MainActor in
        if let aiError = error as? AINetworkError {
            // 检查是否是403错误（已在AINetworkService中显示Toast）
            var is403Error = false
            if case .httpError(let code) = aiError {
                is403Error = (code == 403)
            }
            
            // 403错误已在AINetworkService中显示Toast，跳过
            // 其他错误显示友好提示
            if !is403Error {
                ToastManager.shared.showToast(message: aiError.localizedDescription)
            }
        } else {
            // 对于其他错误，显示通用提示
            ToastManager.shared.showToast(message: "生成失败，请稍后重试")
        }
    }
    
    promise(.failure(error))
}
```

## 错误提示流程

### 403错误（API额度不足）
1. **后端返回403状态码**
2. **AINetworkService检测到403错误**
3. **显示Toast提示：** "API服务暂时不可用，请联系客服或稍后重试"
4. **标记后端为忙碌状态**
5. **返回错误给调用方**

### 其他HTTP错误
1. **后端返回非200状态码**
2. **AINetworkService检测到错误**
3. **标记后端为忙碌状态**
4. **返回错误给调用方**
5. **ContentGeneratorService显示错误提示**

### 其他错误（非HTTP错误）
1. **发生其他类型的错误**
2. **ContentGeneratorService显示通用提示：** "生成失败，请稍后重试"
