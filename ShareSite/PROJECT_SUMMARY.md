# 虫遇 - 穿越时空对话

## 项目概述
虫遇是一款创新的社交应用，允许用户与历史人物进行虚拟对话和互动。通过AI驱动的内容生成，用户可以探索不同时代的思想和文化，创造独特的社交体验。

## 主要功能

### 1. 社交动态
- 用户可以发布、编辑和删除自己的动态
- 支持图片和文字内容
- 支持点赞、评论和收藏功能
- 拖拽调整图片顺序

### 2. 虚拟角色互动
- 与爱因斯坦、莎士比亚、达芬奇等历史人物进行对话
- 历史人物会根据自己的性格和知识背景回复用户
- 支持角色个性化设置

### 3. 虫洞探索
- 探索不同时空的内容和思想
- 虫洞共鸣功能，生成相关联的内容
- 动态控制生成内容的数量

### 4. 用户体验
- 精心设计的界面和交互
- 流畅的动画和过渡效果
- 触觉反馈增强用户体验
- 支持深色和浅色模式
