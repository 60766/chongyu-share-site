# 后端配置验证方法

## 验证 INITIAL_WELCOME_CREDITS 配置

### 方法1：检查配置文件

**本地配置文件：**
```bash
cat backend/production.env | grep INITIAL_WELCOME_CREDITS
```

**预期输出：**
```
INITIAL_WELCOME_CREDITS=600
```

### 方法2：检查服务器启动日志

**查看服务器启动日志：**
```bash
pm2 logs chongyu-backend --lines 50 | grep INITIAL_WELCOME_CREDITS
```

**或者查看完整启动日志：**
```bash
pm2 logs chongyu-backend --lines 100 | grep "\[Config\]"
```

**预期输出：**
```
[Config] Loaded production.env
[Config] INITIAL_WELCOME_CREDITS = 600
```

### 方法3：检查实际赠送记录

**查看服务器日志中的赠送记录：**
```bash
pm2 logs chongyu-backend --lines 200 | grep "新用户.*获得"
```

**预期输出示例：**
```
[Wallet] 新用户 550e8400... 获得 600 虫洞币 (device=xxx)
```

### 方法4：检查交易记录

**查看 server-data.json 中的交易记录：**
```bash
cat backend/server-data.json | grep -A 5 "new_user_welcome" | grep amount
```

**预期输出示例：**
```
"amount": 600
```

### 方法5：直接测试API

**创建一个测试请求：**
```bash
# 使用新的deviceId和token测试
curl -X GET "http://your-server:3000/balance?appAccountToken=test-token-$(date +%s)" \
  -H "X-Device-Id: test-device-$(date +%s)"
```

**检查响应中的余额：**
- 如果设备首次使用，应该返回 `{"balance": 600, ...}`
- 如果设备已使用过，应该返回 `{"balance": 0, ...}`
