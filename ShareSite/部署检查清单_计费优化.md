## 🚨 常见问题排查

### 问题1: 配置未生效（还是扣200币）
**原因**: 服务器未重启
**解决**:
```bash
pm2 restart chongyu-production
pm2 logs chongyu-production | head -30
```

### 问题2: PM2未安装
**解决**:
```bash
npm install -g pm2
cd backend
pm2 start server.js --name chongyu-production
```

### 问题3: 服务器启动失败
**排查**:
```bash
# 检查端口占用
lsof -i :3000

# 手动启动看错误
cd backend
node server.js
```

### 问题4: iOS端显示异常
**原因**: 缓存问题
**解决**: 
1. 重启iOS App
2. 检查后端日志是否有请求
3. 验证 `/api/wallet/balance` 接口
