## 🎯 快速参考

### 如果构建失败

**常见原因**:
1. Xcode缓存问题 → 重启Xcode
2. 模拟器问题 → 重启模拟器
3. DerivedData损坏 → 删除DerivedData

**解决步骤**:
```bash
# 清理DerivedData
rm -rf ~/Library/Developer/Xcode/DerivedData/

# 重新打开项目
open 虫遇.xcodeproj
```

### 如果模拟器闪退

**检查点**:
1. 查看Xcode控制台错误
2. 检查是否有iOS 17+ API调用
3. 查看内存使用情况

**调试方法**:
```
1. Xcode → Debug → Debug Output → Activate Console
2. 运行应用
3. 查找红色错误信息
4. 搜索关键词: "crash", "exception", "assertion"
```
