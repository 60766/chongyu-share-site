# 虫遇应用

## 项目概述
虫遇是一款基于"穿越时空"概念设计的虚拟角色社交平台，通过"虫洞"隐喻，连接用户与不同时代、不同领域的历史人物和虚构角色，促进多元知识探索和深度互动体验。

## 功能模块
- **用户账户管理**：个人资料设置、隐私安全控制、个性化设置
- **角色探索与发现**：按时代/领域分类展示、智能搜索、角色推荐、浏览历史
- **角色互动系统**：实时对话、角色详情页、角色档案查看、话题讨论
- **社交互动功能**：关注系统、评论分享、互动时间线、通知中心
- **创作中心**：自定义角色创建、数据分析
- **系统设置**：互动方式设置、偏好设定、隐私控制

## 技术架构
- **UI框架**：SwiftUI + UIKit (必要时)
- **数据管理**：SwiftData + Combine
- **架构模式**：MVVM
- **网络层**：URLSession + 自定义网络管理器
- **本地存储**：SwiftData + UserDefaults + Keychain

## 页面结构
1. 首页 - 角色推荐和动态
2. 角色探索页 - 分类浏览和搜索
3. 角色详情页 - 角色资料和互动入口
4. 对话聊天页 - 与角色的实时对话
5. 个人空间 - 用户资料和互动历史
6. 设置页面 - 应用配置和偏好设置

## 设计风格
- 主色调：靛蓝色(#4f46e5)
- 辅助色：紫色(#8b5cf6)、蓝色(#60a5fa)
- 背景色：浅灰蓝(#f5f5f7)
- 视觉元素：圆形设计、光晕效果、微妙渐变、时代标识

## 开发规范
- 遵循Swift编码规范
- 使用JSDoc风格的代码注释
- 针对不同设备进行响应式设计
- 支持深色模式和动态字体
