# 虫遇 - 头像系统文档

## 系统概述

头像系统是虫遇应用中的核心组件之一，负责统一管理和显示用户头像和虚拟角色头像。系统遵循"第一性原理"设计，直接使用角色ID作为图片资源名称，不使用额外的映射层，简化了系统架构并提高了可维护性。

## 核心组件

### 1. CharacterAvatarService

中心服务类，提供以下功能：
- 根据角色ID获取对应的头像视图
- 支持多种头像来源：本地图片、系统图标、字母头像
- 处理不同类型角色的特殊显示逻辑

```swift
// 使用示例
let avatarView = CharacterAvatarService.shared.getAvatarView(
    for: characterID,
    name: characterName,
    category: characterCategory,
    size: 40
)
```

### 2. 头像类型

系统支持三种类型的头像：
1. **图片头像**：从本地资源加载的图片
2. **系统图标**：使用SF Symbols的系统图标
3. **字母头像**：使用角色名称首字母的文本头像

## 头像加载流程

1. 尝试直接从本地资源加载图片（使用角色ID作为名称）
2. 尝试从`HistoricalFigures`目录加载图片（格式：`HistoricalFigures/角色ID`）
3. 如果没有找到图片，使用预定义的系统图标和颜色
4. 如果没有预定义图标，使用角色名称的首字母作为头像

## 添加新角色头像

### 步骤1：准备图片
- 准备一张正方形图片，建议尺寸为200x200或更高
- 图片应当清晰且能代表该角色特征
- 推荐使用PNG格式，支持透明背景

### 步骤2：添加到Assets.xcassets
1. 在Xcode中打开项目
2. 找到`Assets.xcassets`资源目录
3. 在`HistoricalFigures`文件夹中创建新的Image Set
4. **重要**：Image Set的名称必须与角色ID完全一致（区分大小写）
5. 将准备好的图片拖入Image Set中

### 步骤3：更新角色数据（如需要）
- 确保`characters.json`中该角色的`id`和`avatarName`字段一致
- 角色ID应当使用小写字母，不含特殊字符

## 注意事项

1. **命名一致性**：角色ID、图片资源名称、JSON数据中的ID必须保持一致
2. **不使用映射**：系统设计原则是直接使用ID，不通过映射表转换
3. **调试信息**：服务类包含丰富的调试日志，可通过控制台查看头像加载过程
4. **系统图标**：为常用角色预定义了系统图标，可在`getIconAndColor`方法中查看和修改

## 常见问题排查

### 头像不显示
- 检查图片是否正确添加到Assets.xcassets的HistoricalFigures目录
- 确认Image Set名称与角色ID完全一致
- 检查控制台日志中的`CharacterAvatarService`相关信息

### 显示默认图标而非自定义图片
- 检查角色ID拼写是否正确
- 确认图片文件格式是否支持
- 查看`checkImageExistence`方法的日志输出

### 系统性能问题
- 图片尺寸过大可能影响性能，建议优化图片大小
- 避免在列表滚动时频繁创建新的头像视图实例
